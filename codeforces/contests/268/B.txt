Existe um cadeado com n butões;
Para ser aberto, os botões devem ser apertados na ordem certa;
Entretanto, ele se mantém pressionado apenas até você errar a combinação;

A entrada é o número de botões;

A saída é o número de vezes a ser pressionado, no pior cenário possível;

#1

diminui em 1, o valor de "pressionadas" de cada camada até n ser 1, é o número de opções
erradas vezes o nível daquela camada + c (sendo esse c o número da camada anterior, considerando a camada 0 com c = 1 também), ficou um pouco confuso mas olha isso:
